# lightsout 关灯游戏

终端版 Lights Out(关灯)谜题: 按下一格会翻转它自己和上下左右的邻居, 目标是把所有灯熄灭。

## 玩法

```bash
python -m lightsout              # 交互玩 5x5
python -m lightsout --size 7     # 7x7
python -m lightsout --solve      # 直接求解并验证
python -m lightsout --solve --seed 42
```

交互中输入 `B3` 或 `2 3`(行 列, 1 起始)翻转一格; 输入 `solve` 让程序自动解; `q` 退出。

## 设计取舍

- **打乱方式保证可解**: 开局从全灭状态随机按若干下得到, 逆操作本身就是一组解, 所以求解器一定能找到解(相容性检查只是兜底)。
- **求解器是 GF(2) 高斯消元**: 把"按/不按"看成 mod 2 未知数, 对每格列方程(它及邻居的按压次数之和 ≡ 当前亮灭), Gauss-Jordan 消元求解。5x5 方程组是奇异的(nullity=2), 消元后自由变量取 0, 对相容的打乱局面总能给出解。
- 纯标准库, 单文件约 200 行。

## 已知局限

- 交互是行输入模式, 每步需回车; 不支持鼠标点击。
- 求解器给出的是"一组解"不是"最少步数解"。
- 棋盘限制 2–9, 无成绩记录。
